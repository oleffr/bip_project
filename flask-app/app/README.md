# Краткое описание директорий

- models

Предназначен для хранения баз данных. Пока пуст

- routes

Предназначен для хранения путей

- services

Туда ляжет вся сторонняя логика

- static и templates

Папки для статичных (js, css) и шаблонных (html) файлов
Все файлы-исключительно заглушки, только для тестирования бэкенда
Глобально, при изменении структуры static и templates, главное правильно указать пути в html
