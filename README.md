# Установка и сохранение

Зависимости хранятся в файле requitements.txt

Чтобы установить виртуальное окружение и зависимости необходимо в директории вызывать init.bat

Если были добавлены новые библиотеки, выполнить update_requitements.bat

Чтобы запустить программу, запускаем виртуальное окружение и запускаем run.py
